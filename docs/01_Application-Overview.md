# OrangeHRM Application Overview

**Author:** Jyothi Aradhya  
**Project:** OrangeHRM Playwright Automation Framework  
**Document:** Application Overview

## 1. Application Under Test

Application: OrangeHRM

Application Type: Web-based Human Resource Management application

## 2. Purpose

OrangeHRM is a web-based HR management application used to manage employee-related processes and HR operations.

For this automation project, OrangeHRM will be used as the Application Under Test (AUT) for developing and demonstrating a Playwright-based UI automation framework.

## 3. Key Functional Areas

The application contains multiple functional areas, including:

- Login / Authentication
- Dashboard
- Admin
- PIM / Employee Management
- Leave
- Time
- Recruitment
- My Info
- Performance
- Directory
- Maintenance
- Buzz

## 4. Automation Focus

The automation project will focus on stable, repeatable, business-relevant UI workflows that provide good regression value.

The objective is not to automate every functionality available in the application.

Test scenarios will be evaluated based on:

- Business criticality
- Repeatability
- Stability
- Regression value
- Technical feasibility
- Maintenance effort
- Automation ROI

## 5. Automation Technology

The project will use:

- Playwright
- TypeScript
- Playwright Test
- Git/GitHub
- GitHub Actions for CI/CD

## 6. Project Objective

The objective is to design and implement a maintainable Playwright automation framework for selected OrangeHRM workflows while demonstrating a structured approach to automation scope, test selection, regression testing, framework design, execution, reporting, and CI/CD.
